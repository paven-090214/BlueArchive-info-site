## 메인 페이지

### 목적

사이트 접속 시 가장 먼저 보이는 페이지이다.  
현재 진행 중인 픽업, 이벤트, 인연랭크 계산, 과거 픽업 기록 이동 영역을 제공한다.

### UI 구성

- 좌측 최상단: 사이트 로고
- 우측 최상단: 학생 검색 영역
- 로고 아래 중앙: `[ 학원 ]`, `[ 학생 목록 ]` 메뉴
- 좌측 중단: 진행 중인 픽업 캐릭터 영역
- 중앙 중단: 현재 진행 중인 이벤트 영역
- 우측 중단: 인연랭크 계산 영역
- 하단: 과거 픽업 기록 이동 영역

### 학생 검색 영역

#### 위치
- 메인 페이지 최상단 우측에 배치한다.
- 사이트 로고와 같은 상단 줄에 위치한다.

#### 구성 요소
- 학생 이름 검색 입력창
- 검색 추천 목록 패널
- 추천 캐릭터 항목
  - 캐릭터 이미지 placeholder
  - 캐릭터 이름

#### 기능
- 사용자가 검색창에 학생 이름을 입력할 수 있다.
- 입력한 글자가 포함된 캐릭터를 추천 목록으로 보여준다.
- 예를 들어 `노아`를 입력하면 `노아`, `노아(파자마)`처럼 이름에 `노아`가 포함된 캐릭터를 표시한다.
- 추천 목록의 각 항목은 캐릭터 이미지와 이름을 나란히 표시한다.
- 추천 항목을 클릭하면 해당 캐릭터 상세 페이지로 이동한다.
- 검색어가 비어 있으면 추천 목록을 표시하지 않는다.
- 검색 결과가 없으면 `검색 결과가 없습니다.` 문구를 표시한다.
- 현재 단계에서는 임시 캐릭터 데이터로 UI만 구현한다.
- 실제 DB 검색 기능은 캐릭터 목록/상세 페이지 구현 이후 연결한다.

#### 이동 경로 예시
- 노아 → `character-detail.html?id=1`
- 노아(파자마) → `character-detail.html?id=2`

### 상단 메뉴

#### 위치
- 사이트 로고 아래 중앙에 배치한다.

#### 구성 요소
- `[ 학원 ]` 버튼
- `[ 학생 목록 ]` 버튼
- 학원 목록 패널

#### 기능
- `[ 학원 ]` 버튼을 클릭하면 학원 목록 패널이 아래로 펼쳐진다.
- `[ 학생 목록 ]` 버튼을 클릭하면 `characters.html`로 이동한다.
- 기존 학생 검색, 메인 카드 영역, 인연랭크 계산 영역은 유지한다.

### 학원 드롭다운 메뉴

#### 표시할 학원 목록

현재 단계에서는 실제 DB 연동 없이 임시 데이터로 다음 학원을 표시한다.

- 게헨나
- 트리니티
- 밀레니엄
- 아비도스
- 백귀야행
- 산해경
- 붉은겨울
- 발키리
- SRT
- 아리우스
- 하이랜더
- 와일드헌트
- 기타

각 학원 카드는 학원 로고 placeholder와 학원 이름을 함께 표시한다.
추후 실제 이미지가 준비되면 각 학원 로고를 연결한다.
#### 구성 요소
- `[ 학원 ]` 버튼
- 학원 목록 패널
- 학원 카드
  - 학원 로고 CSS placeholder
  - 학원 이름



#### 기능
- 처음 화면에서는 `[ 학원 ]` 버튼과 `[ 학생 목록 ]` 버튼을 표시한다.
- 사용자가 `[ 학원 ]` 버튼을 클릭하면 학원 목록 패널이 아래로 펼쳐진다.
- 학원 목록 패널은 격자 형태로 학원 카드를 표시한다.
- 각 학원 카드는 학원 로고와 학원 이름을 함께 보여준다.
- 사용자가 학원 카드를 클릭하면 해당 학원 상세 페이지로 이동한다.
- 현재 단계에서는 임시 학원 데이터로 UI만 구현한다.
- 실제 학원 DB 연동은 이후 단계에서 구현한다.

#### 이동 경로 예시
- 게헨나 → `academy-detail.html?academy=gehenna`
- 트리니티 → `academy-detail.html?academy=trinity`
- 밀레니엄 → `academy-detail.html?academy=millennium`

### 전체 학생 목록 페이지

#### 이동 경로
- `characters.html`

#### 구성 요소
- 공통 헤더
- 학생 검색 영역
- 좌측 필터 영역
- 전체 학생 카드 목록
- 각 학생 카드는 학생증 느낌의 가로형 카드로 표시
- 각 학생 카드의 좌측에는 대표 이미지 placeholder 표시
- 각 학생 카드의 우측에는 학생 이름, 성급, 소속 학원, 소속 동아리, 역할, 공격 타입, 방어 타입 표시
- 공격 타입과 방어 타입은 텍스트가 아니라 색상 배지로 표시

#### 필터 구성 요소
- 학원
- 동아리
- 노란 별 성급 필터
- 공격 타입
- 방어 타입
- 역할

#### 타입 배지 색상
- 공격 타입
  - 폭발: 빨강 계열
  - 관통: 노랑 계열
  - 신비: 파랑 계열
  - 진동: 보라 계열
- 방어 타입
  - 경장갑: 빨강 계열
  - 중장갑: 노랑 계열
  - 특수장갑: 파랑 계열
  - 탄력장갑: 보라 계열

#### 기능
- 메인 페이지의 `[ 학생 목록 ]` 버튼을 클릭하면 이동한다.
- 현재는 임시 학생 데이터를 카드 형태로 표시한다.
- 학생 카드를 클릭하면 `character-detail.html?id=...` 형태로 캐릭터 상세 페이지로 이동한다.
- 필터를 선택하면 임시 학생 데이터 기준으로 학생 카드 목록이 갱신된다.
- 넓은 화면에서는 좌측 필터, 우측 학생 카드 목록 구조로 표시한다.
- 좁은 화면에서는 필터가 위, 학생 카드 목록이 아래에 표시된다.
- 실제 DB 연동은 이후 단계에서 구현한다.

### 기능

- 사이트 로고를 클릭하면 메인 페이지로 이동한다.
- 학원 영역은 `[ 학원 ]` 버튼 클릭 시 펼쳐지는 패널 방식으로 표시한다.
- 학원 카드는 추후 학원 상세 페이지로 이동할 수 있도록 링크를 가진다.
- 학생 목록 버튼은 전체 학생 목록 페이지로 이동한다.
- 진행 중인 픽업 캐릭터 영역은 현재 UI만 구현하고, DB 연동은 나중에 구현한다.
- 현재 진행 중인 이벤트 영역은 현재 UI만 구현하고, DB 연동은 나중에 구현한다.
- 인연랭크 계산 영역은 현재 직접 수정된 UI를 유지하고, 실제 계산 로직은 나중에 구현한다.
- 과거 픽업 기록 영역은 `pickup-history.html`로 이동한다.

### 픽업 기록 페이지

#### 목적
- 과거, 현재, 예정 픽업 기록을 확인하는 페이지이다.

#### 이동 경로
- `pickup-history.html`

#### 구성 요소
- 공통 헤더
- 학생 검색 영역
- 주차 범위 페이지네이션
- 픽업 기록 카드 목록
- 각 픽업 카드의 주차, 픽업 이미지, 픽업 캐릭터, 시작일, 종료일, 픽업 유형
- 검수 필요 항목의 `검수 필요` 배지

#### 기능
- 메인 페이지의 과거 픽업 기록 버튼을 클릭하면 이동한다.
- `data/pickup-candidates.json` 데이터를 기준으로 표시한다.
- 하나의 일정에 여러 픽업 캐릭터가 있으면 캐릭터별 카드로 나누어 표시한다.
- 배포 학생은 데이터에는 유지하지만 기본 화면에는 표시하지 않는다.
- 실제 DB 연동은 이후 단계에서 구현한다.

### 인연랭크 계산기 영역

#### 위치
- 메인 페이지 우측 중단에 배치한다.

#### 구성 요소
- 섹션 제목: 인연랭크 계산기
- 작은 이미지형 안내 박스
- 설명 문구
- 계산기 준비 중 버튼

#### 기능
- 현재는 실제 계산 기능을 구현하지 않는다.
- 현재는 UI만 표시한다.
- 현재 직접 수정된 UI를 유지하며 입력폼 구조로 되돌리지 않는다.
- 추후 인연랭크 계산기 상세 페이지로 이동하도록 연결할 예정이다.

- 동아리 목록 영역보다 위에 배치한다.

#### 구성 요소
- 학원 로고 또는 대표 이미지 placeholder
- 학원 이름
- 학원 설명

#### 기능
- 현재 선택된 학원의 기본 정보를 보여준다.
- 현재는 실제 DB 연동 없이 임시 데이터로 표시한다.
- 추후 `academies` 테이블의 `name`, `logo_url`, `description` 값을 사용해 표시한다.

### 학원 상세 페이지

#### 목적

#### 유지 요소

- 우측 상단 학생 검색 기능을 유지한다.
- 우측 지도/스케줄 영역을 유지한다.

#### 좌측 영역 구조

  - 학원 이름
  - 학원 설명
- 동아리 목록 영역
  - 동아리 이름
  - 동아리 설명
- 동아리 클릭 시 펼쳐지는 캐릭터 목록
  - 캐릭터 이미지 placeholder
  - 캐릭터 이름
  - 캐릭터 상세 페이지 이동 링크

#### 우측 영역 구조
- 학원 지도 placeholder
- 학원 스케줄 placeholder

## 캐릭터 상세 페이지

### 목적

선택한 학생의 프로필, 기본 정보, 스킬, 스탯, 육성 재화, 전용무기 정보를 확인하는 페이지이다.

현재 단계에서는 실제 DB 연동과 계산 로직 없이 임시 데이터와 placeholder로 UI만 구현한다.

### 프로필 이미지 영역

#### 위치
- 캐릭터 상세 페이지 상단 좌측에 배치한다.

#### 구성 요소
- 큰 학생 프로필 이미지 placeholder
- 작은 표정 이미지 placeholder 목록

#### 기능
- 선택한 학생의 대표 이미지를 보여준다.
- 작은 표정 이미지를 클릭하면 추후 대표 이미지가 변경되도록 확장할 예정이다.
- 현재는 실제 이미지 없이 placeholder로 표시한다.

#### 위치

#### 구성 요소
- 이름
- 생일
- 소속 학원
- 공격 타입
- 방어 타입
- 역할

- 현재는 임시 데이터로 표시한다.
- 추후 characters 테이블 또는 관련 테이블과 연결한다.

### 스킬 정보 영역


#### 위치
- 프로필 영역 아래에 배치한다.

#### 구성 요소
- EX 스킬
- 1스킬
- 2스킬
- 3스킬

각 스킬은 다음 요소를 가진다.

- 스킬 아이콘 placeholder
- 스킬 이름
- 스킬 설명
- 우측 상단 스킬 레벨 드롭다운
- 레벨별 수치 표시 영역

#### 스킬 레벨 선택 방식

- 각 스킬 카드의 우측 상단에는 스킬 레벨 선택 옵션을 배치한다.
- 스킬 레벨 선택은 드롭다운 형태로만 만든다.
- EX 스킬은 1~5레벨까지 선택할 수 있다.
- 1스킬, 2스킬, 3스킬은 1~10레벨까지 선택할 수 있다.
- 기존의 1~10 숫자 버튼 목록은 사용하지 않는다.
- 스킬 레벨에는 슬라이드바를 사용하지 않는다.
- 현재는 실제 스킬 수치 계산 없이 선택된 레벨 표시만 변경한다.
- 스킬 설명의 수치는 현재 N으로 표시한다.

#### 기능
- 각 스킬의 설명을 보여준다.
- 각 스킬의 레벨을 선택할 수 있다.
- 기본 스킬 레벨은 1로 표시한다.
- 사용자가 스킬 레벨을 변경하면 선택된 레벨 표시가 바뀐다.
- 현재는 실제 수치 계산 없이 N 또는 임시 수치로 표시한다.
- 추후 선택한 레벨에 따라 실제 스킬 수치가 변경되도록 구현한다.

### 학생 레벨 및 스탯 영역

#### 위치
- 스킬 정보 영역 아래에 배치한다.

#### 구성 요소
- 학생 레벨 숫자 직접 입력창
- 학생 레벨 슬라이드바
- 슬라이드바 옆에 1성부터 5성, 2성부터 4성까지 존재하는 성급, 전용무기 성급이 존재한다.
- 1성부터 5성까진 노란별, 2성부터 4성까진 다른 아이콘이 존재한다.
- 스탯 표시 영역

#### 기능
- 학생 레벨 입력창의 기본값은 1이다.
- 학생 레벨 숫자 입력창은 `type="number"`를 사용한다.
- 숫자 입력창의 최소값은 1, 최대값은 90이다.
- 사용자는 숫자를 직접 입력하거나 숫자 입력창의 위/아래 화살표로 학생 레벨을 조절할 수 있다.
- 사용자는 슬라이드바로도 학생 레벨 값을 조절할 수 있다.
- 숫자 입력창과 슬라이드바는 서로 같은 값을 공유하며 동기화된다.
- 값이 1보다 작아지면 1로, 90보다 커지면 90으로 보정한다.
- 현재는 실제 스탯 계산 없이 N으로 표시한다.
- 사용자는 학생의 현재 성급을 선택할 수 있다.
- 추후 학생 레벨에 따라 HP, 공격력, 방어력 등 스탯이 계산되도록 구현한다.
- 추후 학생 성급에 따라 HP, 공격력, 방어력 등 스탯이 계산되도록 구현한다.

#### 학생 레벨 조정 방식

- 사용자는 숫자 입력창으로 학생 레벨을 직접 수정할 수 있다.
- 사용자는 숫자 입력창의 위/아래 화살표로 학생 레벨을 변경할 수 있다.
- 학생 레벨은 슬라이드바로도 조절할 수 있다.
- 숫자 입력창을 수정하면 슬라이드바 값도 함께 변경된다.
- 슬라이드바를 움직이면 숫자 입력창 값도 함께 변경된다.
- 기본값은 1이다.
- 현재는 실제 스탯 계산 없이 N으로 표시한다.

- 픽업 이미지가 없으면 placeholder를 표시한다.
- 실제 이미지 파일은 아직 연결하지 않는다.

### 픽업 기록 페이지네이션

픽업 기록은 전체 주차를 한 화면에 모두 출력하지 않고, 주차 구간별로 나누어 표시한다.

#### 표시 방식
- 기본적으로 20주차 단위로 페이지를 나눈다.
- 주차 범위 버튼은 `data/pickup-candidates.json`의 `weekLabel` 값을 기준으로 자동 생성한다.
- `2~3주차`처럼 범위 주차는 앞 숫자인 `2`를 기준으로 분류한다.
- 예시:
  - 1페이지: 1~20주차
  - 2페이지: 21~40주차
  - 3페이지: 41~60주차
  - 4페이지: 61~80주차
  - 5페이지: 81~100주차
  - 6페이지: 101~111주차

#### 기능
- 사용자는 상단의 주차 범위 버튼을 클릭하여 해당 구간의 픽업 기록만 볼 수 있다.
- 현재 선택된 주차 범위 버튼은 활성 상태로 표시한다.
- URL에는 `?page=1` 같은 방식으로 현재 페이지 정보를 남긴다.
- 새로고침하면 URL의 `page` 값을 기준으로 같은 주차 범위를 표시한다.
- 실제 DB 연동 없이 `data/pickup-candidates.json` 데이터를 기준으로 동작한다.

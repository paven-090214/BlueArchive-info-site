# 메인 페이지 UI

## 공통 헤더

- 좌측: 로고와 사이트 이름
- 중앙: 통합검색 입력창과 검색 버튼
- 우측: 로그인 | 회원가입
- Enter 키 또는 검색 버튼 클릭 시 통합검색 동작을 실행한다.
- 현재는 실제 검색 결과 화면이 없으므로 임시 처리만 한다.

## 본문 구조

- 상단: ACADEMY 학원 목록 섹션
- 중단 좌측: 진행 중인 픽업
- 중단 중앙: 현재 이벤트
- 중단 우측: 인연랭크 계산기
- 하단 좌측: 과거 픽업 기록
- 하단 우측: 학생 목록

## 동작

- 학원 목록은 항상 표시한다.
- 진행 중인 픽업과 현재 이벤트, 인연랭크 계산기는 기존 카드 구조를 유지한다.
- 진행 중인 픽업 캐릭터가 3명 이상이면 2명 단위 캐러셀로 표시한다.
- 픽업 캐러셀은 제목 오른쪽의 원형 좌우 버튼으로 이동할 수 있으며, 사용자 이동이 없으면 5초마다 다음 페이지로 순환 이동한다.
- 과거 픽업 기록과 학생 목록은 각각 별도 카드와 버튼으로 이동한다.
- 로그인과 회원가입은 UI만 제공한다.

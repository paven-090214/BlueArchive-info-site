# 공통 UI

## 공통 헤더

- 모든 페이지 최상단에 배치한다.
- 좌측에는 사이트 로고를 둔다.
- 우측에는 `통합검색` 입력창을 둔다.
- placeholder는 `통합검색`으로 표시한다.
- 현재 단계에서는 추천 목록이나 자동완성 결과를 표시하지 않는다.
- 통합검색은 추후 학생, 학원, 동아리, 픽업 기록, 이벤트를 대상으로 확장한다.

## 공통 동작

- 사이트 로고를 클릭하면 메인 페이지로 이동한다.
- 공통 헤더의 검색은 페이지별 학생 필터와 분리한다.
- 학생 이름 검색은 `characters.html` 안에서 별도로 제공한다.

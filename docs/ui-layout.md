# UI 레이아웃

## 1. 공통 레이아웃

### 공통 헤더

- 모든 페이지 최상단에 배치한다.
- 좌측에는 사이트 로고를 둔다.
- 우측에는 학생 검색 기능을 둔다.
- 스크롤해도 상단에 고정한다.

---

## 2. 메인 페이지 레이아웃

1. 최상단: 공통 헤더
   - 좌측: 사이트 로고
   - 우측: 학생 검색 영역

2. 학생 검색 영역
   - 우측 상단에 배치한다.
   - 검색 입력창을 둔다.
   - 사용자가 학생 이름을 입력하면 검색창 아래에 추천 목록 패널을 표시한다.
   - 추천 목록은 임시 캐릭터 데이터에서 입력값이 이름에 포함된 항목을 보여준다.
   - 추천 항목은 캐릭터 이미지 placeholder와 캐릭터 이름을 가로로 표시한다.
   - 검색어가 비어 있으면 추천 목록을 숨기고, 결과가 없으면 `검색 결과가 없습니다.`를 표시한다.
   - 현재 단계에서는 UI만 만들고 실제 DB 검색 기능은 이후 단계에서 구현한다.

3. 로고 아래에는 학원 드롭다운 메뉴를 중앙에 배치한다.
   - 처음에는 `[ 학원 ]` 버튼만 표시한다.
   - `[ 학원 ]` 버튼을 클릭하면 학원 목록 패널이 아래로 펼쳐진다.
   - 펼쳐진 학원 목록은 격자 형태로 표시한다.
   - 각 학원은 학원 로고 placeholder와 학원 이름을 함께 표시한다.
   - 학원 카드를 클릭하면 해당 학원 상세 페이지로 이동한다.
   - 현재 단계에서는 임시 학원 데이터와 CSS placeholder만 사용한다.

4. 중단 영역은 3열 구조로 구성한다.
   - 좌측: 진행 중인 픽업 캐릭터
   - 중앙: 현재 진행 중인 이벤트
   - 우측: 인연랭크 계산기 이동 영역
   - 인연랭크 계산기 영역은 현재 직접 수정된 UI를 유지한다.

5. 하단에는 과거 픽업 기록으로 이동하는 영역을 배치한다.

6. 화면이 좁아지면 상단 검색 영역과 중단 3열 구조는 세로로 쌓이도록 한다.

┌──────────────────────────────────────────────┐
│ 로고: BlueArchive Info Site       [학생 검색] │
└──────────────────────────────────────────────┘

                 [ 학원 ]

        클릭 시 아래 학원 목록 패널 표시

┌───────────────┬────────────────┬────────────────────┐
│ 진행 중인 픽업 │ 현재 진행 이벤트 │ 인연랭크 계산기 이동 │
│ 캐릭터 카드들  │ 이벤트 카드들    │ 안내 박스             │
└───────────────┴────────────────┴────────────────────┘

┌──────────────────────────────────────────────┐
│           과거 픽업 기록으로 이동             │
└──────────────────────────────────────────────┘

### 최상단 학생 검색 UI

최상단 영역은 좌우 구조로 구성한다.

- 좌측: 사이트 로고
- 우측: 학생 검색 영역

학생 검색 영역은 다음 구조로 배치한다.

```text
┌──────────────────────────────────────────────┐
│ 로고: BlueArchive Info Site       [학생 검색] │
│                              ┌─────────────┐ │
│                              │ [이미지] 노아 │ │
│                              │ [이미지] 노아(파자마) │
│                              └─────────────┘ │
└──────────────────────────────────────────────┘
```

## 3. 학원 상세 페이지 레이아웃

- 최상단: 공통 헤더
- 본문 좌측: 동아리 목록 영역
- 본문 우측: 학원 지도/스케줄 영역
- 좁은 화면에서는 좌측/우측 영역을 세로로 배치한다.

### 좌측 영역 구성

좌측 영역은 위에서 아래 순서로 다음과 같이 구성한다.

1. 학원 소개 영역
   - 학원 로고 또는 대표 이미지 placeholder
   - 학원 이름
   - 학원 설명

2. 동아리 목록 영역
   - 동아리 목록 영역은 학원 소개 영역 아래에 배치한다.
   - 해당 학원에 존재하는 동아리 목록을 세로로 나열한다.
   - 각 동아리 카드에는 동아리 이름과 동아리 설명을 표시한다.
   - 동아리 카드를 클릭하면 해당 동아리에 소속된 캐릭터 목록이 드롭다운으로 펼쳐진다.

```text
┌──────────────────────────────────────────────┐
│ 로고                              학생 검색 │
└──────────────────────────────────────────────┘

┌─────────────────────┬────────────────────────┐
│ 학원 소개 영역       │ 학원 스케줄/지도 영역    │
│ [학원 로고]          │ [지도 placeholder]       │
│ 게헨나 학원          │ hover 위치 표시 예정     │
│ 학원 설명 문구       │                        │
│                     │                        │
│ 동아리 목록 영역     │                        │
│ [동아리 이름]        │                        │
│ 동아리 설명          │                        │
│ ▼ 캐릭터 목록        │                        │
└─────────────────────┴────────────────────────┘
```

## 캐릭터 상세 페이지

### 목적

선택한 학생의 프로필, 기본 정보, 스킬, 스탯, 육성 재화, 전용무기 정보를 확인하는 페이지이다.

현재 단계에서는 실제 DB 연동과 계산 로직 없이 임시 데이터와 placeholder로 UI만 구현한다.

---

### 프로필 이미지 영역

#### 위치
- 캐릭터 상세 페이지 상단 좌측에 배치한다.

#### 구성 요소
- 큰 학생 프로필 이미지 placeholder
- 각 학생의 프로필 소개

#### 기능
- 선택한 학생의 대표 이미지를 보여준다.
- 현재는 실제 이미지 없이 placeholder로 표시한다.

---

### 캐릭터 기본 정보 영역

#### 위치
- 캐릭터 상세 페이지 상단 우측에 배치한다.

#### 구성 요소
- 이름
- 생일
- 소속 학원
- 공격 타입
- 방어 타입
- 역할
- 나이
- 취미
- 디자이너
- 일러스트레이터
- 성우
- 출시일

#### 기능
- 선택한 학생의 기본 정보를 표 형태 또는 목록 형태로 보여준다.
- 현재는 임시 데이터로 표시한다.
- 추후 characters 테이블 또는 관련 테이블과 연결한다.

---

### 스킬 정보 영역

#### 위치
- 프로필 영역 아래에 배치한다.

#### 구성 요소
- EX 스킬
- 1스킬
- 2스킬
- 3스킬

각 스킬은 다음 요소를 가진다.

- 스킬 아이콘 placeholder
- 스킬 이름
- 스킬 설명
- 우측 상단 스킬 레벨 드롭다운
- 레벨별 수치 표시 영역

#### 기능
- 각 스킬의 설명을 보여준다.
- 각 스킬의 레벨은 카드 우측 상단 드롭다운으로만 선택한다.
- 스킬 레벨에는 슬라이드바를 사용하지 않는다.
- EX 스킬은 `Lv. 1`부터 `Lv. 5`까지만 선택한다.
- 1스킬, 2스킬, 3스킬은 `Lv. 1`부터 `Lv. 10`까지 선택한다.
- 기본 스킬 레벨은 1로 표시한다.
- 사용자가 스킬 레벨을 변경하면 선택된 레벨 표시가 바뀐다.
- 현재는 실제 수치 계산 없이 N 또는 임시 수치로 표시한다.
- 추후 선택한 레벨에 따라 실제 스킬 수치가 변경되도록 구현한다.

---

### 학생 레벨 및 스탯 영역

#### 위치
- 스킬 정보 영역 아래에 배치한다.

```text
┌──────────────────────────────────────────────┐
│ [아이콘] EX 스킬                  [Lv. 1 ▼] │
│ 공격력 N% 데미지를 줍니다.                  │
└──────────────────────────────────────────────┘
```

### 학생 레벨 조정 기능

#### 구성 요소
- 학생 레벨 숫자 입력창
- 학생 레벨 슬라이드바

#### 기능
- 기본 학생 레벨은 1이다.
- 학생 레벨은 최소 1, 최대 90까지 입력할 수 있다.
- 사용자는 숫자 입력창에 직접 레벨을 입력할 수 있다.
- 사용자는 숫자 입력창의 위/아래 화살표로 레벨을 변경할 수 있다.
- 사용자는 슬라이드바를 움직여 레벨을 변경할 수 있다.
- 숫자 입력창 값이 바뀌면 슬라이드바 값도 함께 바뀐다.
- 슬라이드바 값이 바뀌면 숫자 입력창 값도 함께 바뀐다.
- 현재는 실제 스탯 계산 없이 N으로 표시한다.

```text
┌────────────────────────────────────────────────────────────────────┐
│ 학생 레벨: [ 1 ]       Lv. 1 ●───────────────────── Lv.90           │
└───────────────────────────────────────────────────────────────────┘
```

---

### 필요 재화 영역

#### 위치
- 학생 레벨 및 스탯 영역 아래에 배치한다.

#### 구성 요소
- 재화 이미지 placeholder
- 재화 이름
- 필요 수량

#### 기능
- 선택한 학생 레벨과 스킬 레벨을 기준으로 필요한 재화를 보여줄 예정이다.
- 현재는 실제 계산 없이 N으로 표시한다.
- 추후 1레벨부터 사용자가 선택한 레벨까지 필요한 재화를 계산한다.

---

### 전용무기 영역

#### 위치
- 필요 재화 영역 아래에 배치한다.

#### 구성 요소
- 전용무기 이미지 placeholder
- 전용무기 이름
- 전용무기 효과 설명
- 전용무기 레벨별 수치 표시

#### 기능
- 학생의 전용무기 정보를 보여준다.
- 전용무기 효과는 스킬 영역과 비슷한 방식으로 표시한다.
- 현재는 실제 계산 없이 N으로 표시한다.
- 추후 전용무기 레벨에 따라 효과 수치가 변경되도록 구현한다.

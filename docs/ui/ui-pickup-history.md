# 픽업 기록 페이지

## 본문 구조

- 최상단 : `docs\ui\ui-common.md`를 참조한다.
- 상단 : 페이지 이동 버튼
- 본문 : 과거 픽업 기록 표시
- 하단 : 페이지 이동 버튼

## 픽업 기록 카드 구성 요소

- 주차
- 픽업 이미지
- 픽업 캐릭터 이름
- 시작일
- 종료일
- 픽업 유형
- 검수 필요 배지

### 픽업 기록 카드 레이아웃

픽업 기록 카드는 주차 단위로 표시한다.

카드 상단에는 주차와 상태를 표시한다.

카드 본문은 다음 순서로 구성한다.

1. 픽업 이미지
2. 픽업 캐릭터
3. 시작일
4. 종료일
5. 픽업 유형

픽업 이미지가 없으면 placeholder를 표시한다.

```text
┌────────────────────────────────────────────────────────┐
│ 1주차                                  종료             │
│                                                        │
│ [픽업 이미지]  픽업 캐릭터   시작일   종료일   픽업 유형   │
│               시로코, 호시노  21.11.09 21.11.16 기존     │
└────────────────────────────────────────────────────────┘
```

## 상단, 하단 버튼 표시 방식

- 기본적으로 20주차 단위로 페이지를 나눈다.
- 주차 범위 버튼은 `data/pickups.json`의 `weekLabel` 값을 기준으로 자동 생성한다.
- `2~3주차`처럼 범위 주차는 앞 숫자인 `2`를 기준으로 분류한다.
- 예시:
  - 1페이지: 1~20주차
  - 2페이지: 21~40주차
  - 3페이지: 41~60주차
  - 4페이지: 61~80주차
  - 5페이지: 81~100주차
  - 6페이지: 101~111주차

### 페이지네이션

픽업 기록은 20주차 단위로 나누어 표시한다.

페이지네이션은 구간 버튼 방식으로 구성한다.

```text
[<<] [<] [1~20주차] [21~40주차] [41~60주차] [61~80주차] [81~100주차] [>] [>>]
```

## 기능
- 사용자는 상단의 주차 범위 버튼을 클릭하여 해당 구간의 픽업 기록만 볼 수 있다.
- 현재 선택된 주차 범위 버튼은 활성 상태로 표시한다.
- URL에는 `?page=1` 같은 방식으로 현재 페이지 정보를 남긴다.
- 새로고침하면 URL의 `page` 값을 기준으로 같은 주차 범위를 표시한다.
- 실제 DB 연동 없이 `data/pickups.json` 데이터를 기준으로 동작한다.

## 추가할 기능

- 학생 카드를 클릭하면 `character-detail.html?id=...` 형태의 상세 페이지로 이동한다.
`character-detail.html`

### 이동 경로 예시
- 노아 → `character-detail.html?id=noa`
- 케이 → `character-detail.html?id=kei`

# 공통 UI

## 공통 헤더

- 모든 페이지 최상단에 배치한다.
- 좌측에는 사이트 로고를 둔다.
- 중단에는 `통합검색` 입력창을 둔다.
- 우측에는 `로그인|회원가입` 이동창을 둔다.
- placeholder는 `통합검색`으로 표시한다.
- 스크롤해도 상단에 고정한다.

```text
┌──────────────────────────────────────────────────────────────┐
│ BA BlueArchive Info Site    [ 통합검색 ]     로그인 | 회원가입 │
└──────────────────────────────────────────────────────────────┘
```

## 공통 동작

- 사이트 로고를 클릭하면 메인 페이지로 이동한다.
- 공통 헤더의 검색은 페이지별 학생 필터와 분리한다.
- 학생 이름 검색은 `characters.html` 안에서 별도로 제공한다.

## 기능
- 사용자가 페이지 이동 전 공통 검색 입력창을 사용할 수 있다.
- 현재 단계에서는 입력창과 검색 버튼만 제공하고 결과 목록은 표시하지 않는다.
- Enter 키 또는 검색 버튼 클릭 시 임시 검색 동작을 실행한다.
- 추후 `search.html?q=검색어` 형태로 학생, 학원, 동아리, 픽업 기록, 이벤트를 대상으로 확장한다.

## 추가할 기능

- 통합 검색으로 학원 상세페이지
    - ex : `academy-detail.html?academy=gehenna`
- 학생의 상세 기록
    - ex : `character-detail.html?id=noa`
- 현재, 과거 이벤트의 상세 페이지로 이동 가능한 기능
- 작성한 텍스트를 포함하는 관련 검색어를 아래 표시한다. 만약 esc를 누르거나 커서 호버가 끝나거나 다른 곳을 클릭하면 사라진다.

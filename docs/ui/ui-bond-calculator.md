# 인연랭크 계산 페이지 ui

## 본문 구조
- 최상단 : `docs\ui\ui-common.md`를 참조한다.
- 좌측 : 현재 내가 선택할 학생
- 우측 : 계산 결과
- 하단 : 선물 목록

## 레이아웃

### 좌측
- 펏 페이지 로드시 기본 학생으로 아루를 표시한다.
- 학생 이름 검색에 한글자 타이핑이 학생 목록에 포함되는 학생을 아래로 드롭 다운한다.
- 아래 현재 랭크와 목표 랭크를 선택한다.
- 고정값인 카페 상호작용과 스케줄 포인트를 표시한다.

### 우측
- 계산 결과를 나타내는 ui
- 다음 랭크까지 필요한 point
- 목표 랭크까지 필요한 point
- 선물로 획득한 총 인연 포인트
- 카페 상호작용 필요 횟수
- 스케줄 필요 횟수

### 하단

#### 선물 목록
- 학생이 선호하는 선물만 표시한다.
- 하단 영역의 우측 상단에 선호 선물 보기 버튼을 클릭하면 모든 선물보기 버튼으로 바뀐다.
- 클릭 효과마다 모든 선물, 선호 선물의 목록을 보여준다.
- 선물에 따라 좌측의 계산 값이 변경된다.
- 선물 수량이 바뀌면 계산 결과가 즉시 갱신되는 구조를 유지한다.
- 선물 목록은 상단 영역 아래에 넓은 grid로 배치한다.

#### 선물 ui
각 선물 카드는 다음 요소를 가진다.

- 선물 이미지 placeholder
- 선물 이름
- 선물 등급
- 선호도
- 해당 학생에게 주는 인연 포인트
- 수량 입력칸
- `-` 버튼
- `+` 버튼

선물 이름이 길 경우 줄바꿈하거나 말줄임 처리한다.

선물 이미지는 없을 경우 placeholder를 표시한다.

## 기능
- 인연랭크 계산기 상세 규칙은 `spec-bond-calculator.md`를 기준으로 한다.

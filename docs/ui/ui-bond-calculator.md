# 인연랭크 계산 페이지 ui

## 본문 구조
- 최상단 : `docs\ui\ui-common.md`를 참조한다.
- 좌측 : 현재 내가 선택할 학생
- 우측 : 계산 결과
- 하단 : 선물 목록

## 레이아웃

### 좌측
- 펏 페이지 로드시 기본 학생으로 아루를 표시한다.
- 학생 이름 검색에 한글자 타이핑이 학생 목록에 포함되는 학생을 아래로 드롭 다운한다.
- 아래 현재 랭크와 목표 랭크를 선택한다.
- 고정값인 카페 상호작용과 스케줄 포인트를 표시한다.

### 우측
- 계산 결과를 나타내는 ui
- 다음 랭크까지 필요한 point
- 목표 랭크까지 필요한 point
- 선물로 획득한 총 인연 포인트
- 카페 상호작용 필요 횟수
- 스케줄 필요 횟수

### 하단

#### 선물 목록
- 학생이 선호하는 선물만 표시한다.
- 하단 영역의 우측 상단에 선호 선물 보기 버튼을 클릭하면 모든 선물보기 버튼으로 바뀐다.
- 클릭 효과마다 모든 선물, 선호 선물의 목록을 보여준다.
- 선물에 따라 좌측의 계산 값이 변경된다.
- 선물 수량이 바뀌면 계산 결과가 즉시 갱신되는 구조를 유지한다.
- 선물 목록은 상단 영역 아래에 넓은 grid로 배치한다.

#### 선물 ui
각 선물 카드는 다음 요소를 가진다.

- 선물 이미지 placeholder
- 선물 이름
- 선물 등급
- 선호도 표정 이미지
- 해당 학생에게 주는 인연 포인트
- 수량 입력칸
- `-` 버튼
- `+` 버튼
- 보유 수량

선호도 표정 이미지는 선물 아이콘과 별도로 표시한다.
선호도 표정 이미지는 선물 이미지 사각형의 우측 하단에 겹쳐 표시하며, 기본 크기는 가로 30px, 세로 30px이다.
표정 이미지는 선물 이미지 사각형의 우측 하단 바깥으로 오른쪽 6px, 아래쪽 6px만큼 튀어나오게 배치한다.

선호도 라벨은 계산 규칙의 등록 없음 또는 `null`, `preferred`, `liked` 값을 각각 기본, 좋아함, 호감으로 표시한다.

표정 이미지는 계산 규칙에 따라 다음 경로의 이미지를 사용한다.

- `images/gift-ranks/normal.webp`
- `images/gift-ranks/preferred.webp`
- `images/gift-ranks/liked.webp`
- `images/gift-ranks/favorite.webp`

선물 이름이 길 경우 줄바꿈하거나 말줄임 처리한다.

선물 이미지는 없을 경우 placeholder를 표시한다.

선물 카드 안의 포인트, 이미지, 수량 컨트롤, 보유 수량은 일정한 세로 간격으로 배치한다.
보유 수량은 수량 컨트롤 아래에 `보유 n개` 형식으로 표시한다.
현재 유저 보유 재화 데이터가 없으면 보유 수량은 0개로 표시한다.
수량 입력칸의 브라우저 기본 증감 버튼은 표시하지 않고, 수량 변경은 입력칸 양옆의 `-`, `+` 버튼으로 조작한다.
보유 수량은 참고용 표시값이며, 수량 입력칸은 목표 계산을 위해 보유 수량보다 큰 값을 입력할 수 있다.

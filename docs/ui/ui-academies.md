# 학원 상세 페이지 ui

## 본문 구조

- 최상단: `docs\ui\ui-common.md`를 참조한다.
- 본문 좌측: 동아리 목록 영역
- 본문 우측: 학원 지도/스케줄 영역
- 좁은 화면에서는 좌측/우측 영역을 세로로 배치한다.

### 좌측 영역 구성

좌측 영역은 위에서 아래 순서로 다음과 같이 구성한다.

1. 학원 소개 영역
   - 학원 로고 또는 대표 이미지 placeholder
   - 학원 이름
   - 학원 설명

2. 동아리 목록 영역
   - 동아리 목록 영역은 학원 소개 영역 아래에 배치한다.
   - 해당 학원에 존재하는 동아리 목록을 세로로 나열한다.
   - 각 동아리 카드에는 동아리 이름과 동아리 설명을 표시한다.
   - 동아리 카드를 클릭하면 해당 동아리에 소속된 캐릭터 목록이 드롭다운으로 펼쳐진다.

3. 동아리 클릭 시 펼쳐지는 캐릭터 목록
  - 캐릭터 이미지는 학생 데이터의 `iconImageUrl`을 우선 사용한다.
  - `iconImageUrl`이 없으면 기존 이미지 필드 또는 placeholder를 사용한다.
  - 캐릭터 이름
  - 캐릭터 상세 페이지 이동 링크

### 우측 영역 구성

1. 학원의 스케줄 이미지를 표시한다.
2. 이미지 아래에 각 학원의 스케줄(게임 내에 이벤트 장소)을 작성한다.
3. - 학원 데이터의 `mapImageUrl` 값을 사용한다.
```text
┌─────────────────────┬────────────────────────┐
│ 학원 소개 영역       │ 학원 스케줄/지도 영역    │
│ [학원 로고]          │ [지도 placeholder]      │
│ 게헨나 학원          │                        │
│ 학원 설명 문구       │                        │
│                     │                        │
│ 동아리 목록 영역     │  학원 스케줄           │
│ [동아리 이름]        │       장소             │
│ 동아리 설명          │       장소             │
│ ▼ 캐릭터 목록        │                        │
└─────────────────────┴────────────────────────┘
```

## 기능

- 동아리 박스를 클릭하여 동아리에 어떤 학생이 소속되어있는지 알 수 있다.
- 학생을 클릭시 그 학생의 상세 페이지로 이동한다.
- 선택한 학원의 기본 정보, 동아리 목록, 동아리별 캐릭터 목록, 지도/스케줄 placeholder를 보여준다.

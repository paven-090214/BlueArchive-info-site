# 캐릭터 상세 페이지 ui

## 기능

선택한 학생의 프로필, 기본 정보, 스킬, 스탯, 육성 재화, 전용무기 정보를 확인하는 페이지

## 본문 구조

- 최상단: `docs\ui\ui-common.md`를 참조한다.
- 상단 좌측: 학생의 이미지및 성 포함 이름 및 공격타입, 방어타입, 포지션, 역할
- 상단 우측: 학생의 기본 정보 및 지역 적성 (기본 정보에 대한 상세 값은 아래에 작성한다.)
- 중단 : 스킬, 성장 설정, 장비, 애장품, 스탯, 재화 계산
- 하단 : 전용무기 상세
- 최하단 : 메모리얼 영역

## 레이아웃

### 상단 좌측
- 학생의 이미지가 들어간다.
- 그 아래에 학생의 fullName이 들어간다.
- fullName 아래에 학생의 공격타입, 방어타입, 역할, 포지션이 들어간다.
    - 각 공격타입, 방어타입엔 각 타입에 색상의 배지가 들어간다.
        - `docs\ui\ui-chracter.md`의 `#### 타입 배지 색상` 참조
    - 포지션에는 각 이미지가 존재한다. 그 이미지 아래 포지션 문자열이 들어간다
- 그 아래에 학생의 profile이 문자열로 작성된다.

```text
┌──────────────────────────────┐
│          [학생 이미지]        │
│                              │
│                              │
│ 텐도 케이  [공격 타입] [역할]  │
│  텐도 케이                     │
│          [방어 타입][포지션 이미지]│
│                               │
│                              │
│ 학생 profile 설명 문구         │
└──────────────────────────────┘
```

### 상단 우측
- 학생의 기본 정보를 표시한다.

#### 표시 목록
- 이름
- 전투 구분 (스트라이커 or 스페셜)
    - 스트라이커(#e9414f), 스페셜(#1da9e8)에 따라 배지 색상을 다르게 표시할 예정
- 생일
- 소속 학원 (fullName)
- 나이
- 디자이너
- 일러스트레이터
- 성우
- 출시일
- 총기 종류
- 취미
- 지역 적성

```text
┌───────────────────────────────────┐
|학생 기본 정보          [전투 구분]  |
|[이름]                   [생일]     |
|  임의의 값           임의의 값      |
|                                   |
|[소속 학원]             [나이]     |
|임의의 값            임의의 값      |
|                                  |
|[총기 종류]              [디자이너]  |
|임의의 값        임의의 값   |
|                                  |
|[일러스트레이터]          [성우]   |
|임의의 값             임의의 값    |
|                                  |
|[출시일]              [취미]       |
|임의의 값             임의의 값     |
| 지역 적성                         |
|┌────────┐  ┌───────┐  ┌───────┐   |
|│[시가지] |  | [야외]|  | [실내]|   │
|│[표정]   |  | [표정]|  | [표정]|   │
|└────────┘  └───────┘  └───────┘   |
└───────────────────────────────────┘
```
##### 지역적성
- 지역에는 시가지, 야외, 실내가 존재한다. 
- 이 세 가지 지역을 이미지로 나타낼 예정
- 각 학생마다 지역에 대응하는 랭크기 존재한다.
- 각 랭크도 이미지 파일 존재

## 본문

### 스킬 정보 영역
- 프로필 영역 아래에 배치한다.

##### 구성 요소
- EX 스킬
- 1스킬
- 2스킬
- 3스킬

각 스킬은 다음 요소를 가진다.

- 스킬 아이콘 placeholder
- 스킬 이름
- 스킬 설명
- 우측 상단 스킬 레벨 드롭다운
- 레벨별 수치 표시 영역

#### 기능
- 각 스킬의 설명을 보여준다.
- 각 스킬의 레벨은 카드 우측 상단 드롭다운으로만 선택한다.
- 스킬 레벨에는 슬라이드바를 사용하지 않는다.
- EX 스킬은 `Lv. 1`부터 `Lv. 5`까지만 선택한다.
- 1스킬, 2스킬, 3스킬은 `Lv. 1`부터 `Lv. 10`까지 선택한다.
- 기본 스킬 레벨은 1로 표시한다.
- 사용자가 스킬 레벨을 변경하면 선택된 레벨 표시가 바뀐다.
- 추후 선택한 레벨에 따라 실제 스킬 수치가 변경되도록 구현한다.
- 스킬 레벨에는 슬라이드바를 사용하지 않는다.


#### EX 스킬 예시

```text
┌───────────────────────────────────────────────────────┐
|                               현재        목표         |
│ [아이콘] EX 스킬              [Lv. 1 ▼]  [Lv. 5 ▼]     │
│ 공격력 N% 데미지를 줍니다.                              │
└────────────────────────────────────────────────────────┘
```

#### 기능
- 각 스킬의 설명을 보여준다.
- 각 스킬의 레벨을 선택할 수 있다.
- 기본 스킬 레벨은 1로 표시한다.
- 사용자가 스킬 레벨을 변경하면 선택된 레벨 표시가 바뀐다.
- 현재는 실제 수치 계산 없이 N 또는 임시 수치로 표시한다.
- 추후 선택한 레벨에 따라 실제 스킬 수치가 변경되도록 구현한다.

### 학생 성장 설정 영역
학생 레벨 및 스택 영역 아래에는 학생의 성장 상태를 설정하는 영역을 배치한다.

이 영역은 다음 순서로 구성한다.

1. 학생 레벨과 성급 영역
   - 학생 레벨 숫자 입력창
   - 학생 레벨 슬라이드바
   - 1성부터 5성까지 선택 가능한 별 표시 UI
   - 노란 별 아이콘을 사용한다.
   - 여섯 번째 부터 아홉 번째까지의 별은 선택 가능한 별 표시 UI
   - 기존과 다른 별 아이콘 사용한다.

2. 장비 영역
   - 장비 1
   - 장비 2
   - 장비 3
   - 각 장비 카드는 스킬 카드와 유사한 구조로 배치한다.
   - 왼쪽에는 장비 아이콘을 배치한다.
   - 오른쪽에는 장비 이름과 장비 효과 설명을 배치한다.
   - 오른쪽 상단에는 장비 티어 선택 UI를 배치한다.

3. 애장품 영역
   - 애장품이 존재하지 않는 학생이라면 애장품이 존재하지 않는다는 문구를 대신 띄우고 선택창이 보이면 안된다.
   - 애장품 카드는 장비 카드와 유사한 구조로 배치한다.
   - 왼쪽에는 애장품 아이콘을 배치한다.
   - 오른쪽에는 애장품 이름과 애장품 효과 설명을 배치한다.
   - 오른쪽 상단에는 애장품 티어 선택 UI를 배치한다.
   - 애장품 티어는 미선택, 1티어, 2티어를 사용한다.
   - 미선택은 애장품을 장착하지 않은 상태로 처리한다.

#### 위치
- 스킬 정보 영역 아래에 배치한다.

#### 레벨, 성급 성장 레이아웃

```text
┌──────────────────────────────────────────────┐
| 성장 설정                                     |
│ 학생 레벨: [ 1 ]     Lv. 1 ●───────── Lv.90  │
|목표 성급                                     |
| ⭐⭐⭐⭐⭐🔷🔷🔷🔷                       |
└───────────────────────────────────────────────┘
```

#### 기능
- 학생 레벨 입력창의 기본값은 1이다.
- 사용자는 숫자를 직접 입력하거나 숫자 입력창의 위/아래 화살표로 학생 레벨을 조절할 수 있다.
- 사용자는 슬라이드바로도 학생 레벨 값을 조절할 수 있다.
- 숫자 입력창과 슬라이드바는 서로 같은 값을 공유하며 동기화된다.
- 값이 1보다 작아지면 1로, 90보다 커지면 90으로 보정한다.
- 사용자는 학생의 현재 성급을 선택할 수 있다.
- 추후 학생 레벨에 따라 HP, 공격력, 방어력 등 스탯이 계산되도록 구현한다.
- 1성부터 5성까진 노란별, 전용무기1성부터 4성까진 파란 별이 존재한다.
- 아이콘을 클릭시 기본 아이콘이 아이콘이 변경된다.
- 성급이 변경 되었을 경우 스탯도 변화한다.

#### 위치
- 학생 레벨, 학생 성급, 전용무기 성급, 장비, 애장품 설정 영역 아래에 배치한다.

#### 구성 요소
- 공격력
- 방어력
- 체력
- 치유력
- 명중
- 회피
- 치명 수치
- 치명 대미지
- 안정성
- 사거리
- CC 강화력
- CC 저항력
- 공격 속도
- 이동 속도
- 코스트 회복력
- 탄약

#### 기능
- 학생의 스탯은 학생 레벨, 학생 성급, 전용무기 성급, 장비 티어, 애장품 티어에 따라 변경될 예정이다.


### 필요 재화 영역

#### 위치
- 학생 레벨 및 스탯 영역 아래에 배치한다.

#### 구성 요소
- 재화 이미지 placeholder
- 재화 이름
- 필요 수량
- 학생 레벨 성장 재화
- 스킬 성장 재화
- 장비 제작 도면
- 애장품 제작 및 성장에 필요한 선물


#### 기능
- 선택한 학생 레벨과 스킬 레벨을 기준으로 필요한 재화를 보여줄 예정이다.
- 현재는 실제 계산 없이 N으로 표시한다.
- 추후 현재 레벨부터 사용자가 선택한 레벨까지 필요한 재화를 계산한다.

### 전용무기 영역

#### 위치
- 필요 재화 영역 아래에 배치한다.

#### 구성 요소
- 전용무기 이미지 placeholder
- 전용무기 이름
- 전용무기 효과 설명
- 전용무기 레벨별 수치 표시

#### 기능
- 학생의 전용무기 정보를 보여준다.
- 전용무기 효과는 스킬 영역과 비슷한 방식으로 표시한다.
- 현재는 실제 계산 없이 N으로 표시한다.
- 추후 전용무기 레벨에 따라 효과 수치가 변경되도록 구현한다.
- 전용무기는 Level 1, Level 30,	Level 40,	Level 50, Level 60,	Level 70 칸만 존재한다. 이 칸은 효과 아래 존재한다.
- 각 칸에 맞는 카디널리티로 공격력 증가령과 체력 증가량이 적혀있다.

### 메모리얼 영역

#### 위치
- 전용무기 영역 아래에 배치한다.

```text
┌────────────────────────────────────┐
│ 메모리얼                            │
│ [이미지 또는 GIF placeholder]        │
└────────────────────────────────────┘
```

#### 구성 요소
- 메모리얼 이미지 또는 GIF placeholder
- 메모리얼 제목 또는 설명

#### 기능
- 해당 학생의 메모리얼 이미지 또는 GIF를 표시한다.
- 현재 단계에서는 실제 파일을 연결하지 않고 placeholder로 표시한다.
- 추후 이미지 또는 GIF 파일이 준비되면 연결한다.

# 학생 목록 UI

## 본문 구조
- 최상단 : `docs\ui\ui-common.md`를 참조한다.
- 좌측 학생 필터 기능
- 우측 : 필터된 학생들 목록

## 레이아웃
- 넓은 화면에서는 좌측에 필터 영역, 우측에 학생 카드 목록을 배치한다.
- 좁은 화면에서는 필터 영역이 위로 올라가고 학생 카드 목록이 아래에 표시된다.

```text
┌───────────────┬──────────────────────────────┐
│ 필터           │ 학생 카드 목록                 │
│ 학원           │ [학생 카드] [학생 카드]         │
│ 동아리         │ [학생 카드] [학생 카드]         │
│ 성급           │                              │
│ 공격 타입      │                              │
│ 방어 타입      │                              │
│ 역할           │                              │
|  포지션        |                              |
|  전투 구분      |                             |
└───────────────┴──────────────────────────────┘
```

### 좌측 검색 기능
- 데스크톱 화면에서는 학생 목록 왼쪽에 배치한다.
- 모바일 화면에서는 학생 목록 위쪽에 배치한다.
- 이름 검색 시 현재 타이핑에 맞춰 포함하는 학생만 결과에 표시
- 동아리가 선택 되어있다가 학원 변경시 동아리 전체로 변경
- 필터 초기화 버튼을 누르면 전체 학생 목록을 다시 표시한다.

### 필터 구성 요소
- 학원
- 동아리
- 노란 별 성급 필터
- 공격 타입
- 방어 타입
- 역할
- 포지션
- 전투 구분

### 우측 학생 목록

#### 학생 목록 페이지 학생 카드

- 각 학생 카드는 학생증 느낌의 가로형 카드로 표시
- 각 학생 카드의 우측에는 학생 이름, 성급, 소속 학원, 소속 동아리, 역할, 공격 타입, 방어 타입 표시
- 공격 타입과 방어 타입은 텍스트가 아니라 색상 배지로 표시
- 클릭시 그 학생의 상세 페이지로 이동


```text
┌────────────────────────────────────────────┐
│ [대표 이미지]  학생 이름                    │
│                성급                         │
│                소속 학원 / 동아리            │
│                역할                         │
│                공격 타입 배지               │
│                방어 타입 배지               │
└────────────────────────────────────────────┘
```

#### 학생 카드 구성
- 대표 이미지는 학생 데이터의 `portraitImageUrl`을 우선 사용한다.
- 이미지가 없으면 기존 placeholder를 표시한다.
- 학생 이름
- 성급
- 소속 학원
- 공격 타입
- 방어 타입
- 역할

#### 타입 배지 색상
- 공격 타입
  - 폭발: 빨강 계열
  - 관통: 노랑 계열
  - 신비: 파랑 계열
  - 진동: 보라 계열
- 방어 타입
  - 경장갑: 빨강 계열
  - 중장갑: 노랑 계열
  - 특수장갑: 파랑 계열
  - 탄력장갑: 보라 계열

## 기능
- 학생 카드를 클릭하면 `character-detail.html?id=slug` 형태로 이동한다.
- 필터를 선택하면 조건에 맞는 학생 카드만 표시한다.

## 추가할 기능
- 아직 포지션, 전투 구분으로 구분 기능이 존재하지 않는다.
- 필터 초기화 버튼

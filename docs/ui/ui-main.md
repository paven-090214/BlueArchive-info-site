# 메인 페이지 UI

## 본문 구조
- 최상단 : `docs\ui\ui-common.md`를 참조한다.
- 상단: ACADEMY 학원 목록 섹션
- 중단 좌측: 진행 중인 픽업
- 중단 중앙: 현재 이벤트
- 중단 우측: 인연랭크 계산기
- 하단 좌측: 과거 픽업 기록
- 하단 우측: 학생 목록

## 2. 메인 페이지 레이아웃

### 최상단 공통 헤더

`docs\ui\ui-common.md`를 참조한다.

### 상단 학원 목록 영역

- `ACADEMY` 제목과 `학원 목록` 제목을 표시한다.
- 학원 목록은 격자 형태로 표시한다.
- 각 학원은 학원 로고 placeholder와 학원 이름을 함께 표시한다.

### 중단 영역은 3열 구조로 구성한다.

- 좌측: 진행 중인 픽업 캐릭터영역으로 오늘 날짜에 따라 현재 픽업중인 캐릭터를 표시한다.
- 중앙: 진행 중인 이벤트 영역으로 오늘 날짜에 따라 현재 진행중인 이벤트를 표시한다.
- 우측: 인연랭크 계산기 이동 영역이다.
    - `bond-calculator.html`으로 이동한다.

```text
┌───────────────┬────────────────┬────────────────────┐
│ 진행 중인 픽업 │ 현재 진행 이벤트 │ 인연랭크 계산기 이동│
│ 캐릭터 카드들  │ 이벤트 카드들    │     안내 박스      │
└───────────────┴────────────────┴────────────────────┘
```

###  화면이 좁아지면 상단 검색 영역과 중단 3열 구조, 하단 2열 구조는 세로로 쌓이도록 한다.

### 하단 영역

- 좌측: 과거 픽업 기록이다.
    - `pickup-history.html`로 이동한다.
- 우측: 학생 목록으로 학생 검색 기능이다.
    - `characters.html`로 이동한다.

```text
┌──────────────────────┬──────────────────────┐
│ 과거 픽업 기록        │ 학생 목록             │
│ [기록 보기]           │ [학생 목록 보기]      │
└──────────────────────┴──────────────────────┘
```

## 동작

- 학원 목록의 학원 로고 및 이름을 클릭하면 그 학원의 상세 페이지로 이동한다.
    - 이동 경로 예시 :  `academy-detail.html?academy=gehenna`
    - 밀레니엄 → `academy-detail.html?academy=millennium`
- 진행 중인 픽업과 현재 이벤트, 인연랭크 계산기는 기존 카드 구조를 유지한다.
- 인연랭크 계산기 상세 페이지로 이동할 수 있다.
- 진행 중인 픽업 캐릭터가 3명 이상이면 2명 단위 캐러셀로 표시한다.
- 픽업 캐러셀은 제목 오른쪽의 원형 좌우 버튼으로 이동할 수 있으며, 사용자 이동이 없으면 5초마다 다음 페이지로 순환 이동한다.
- 로그인과 회원가입은 UI만 제공한다.

## 추가할 기능

- 현재 픽업중인 캐릭터를 클릭하면 그 학생의 상세 페이지로 이동한다.
    ex : `character-detail.html?id=kei`
- 현재 진행중인 이벤트를 클릭하면 이벤트 상세 페이지로 이동한다.

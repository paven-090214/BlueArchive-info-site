지금 할 계획을 설명할께. 인터뷰 하자.
- 학생의 애장품이 존재하는 여부에 따른 표시 여부를 정할꺼야. 없을 경우 영역을 표시하지 않음
- 필요 재화창은 드롭페이지로 보일수도 안보일수도 있도록 할 예정이야. 처음 페이지 로드시 표시하지않고 클릭시 드롭다운으로 표시예정
- 전용무기 성급에 따른 전용무기의 레벨재화도 넣을 예정이야.
3번에 관한 자세한 사항 : 
- data\growth\weapons_level_cost_table.csv에 계산 테이블 넣어뒀어.
- data\growth\exclusive_weapon_enhancement_items.csv에는 규칙을 넣어뒀어.
계산 요구사항:
- weapons_level_cost_table.csv를 기준으로 현재 전용무기 레벨에서 목표 전용무기 레벨까지 필요한 경험치와 크레딧을 계산, 그 경험치량에 대한 아이템 수량 계산
- exclusive_weapon_enhancement_items.csv를 기준으로 강화 재료의 기본 경험치와 무기 타입별 1.5배 보너스를 적용
- 학생의 전용무기 weapon_type에 따라 보너스 적용 여부를 판단해야해
- bonus_weapon_types가 ALL이면 모든 무기 타입에 1.5배 보너스를 적용해
- bonus_weapon_types는 CSV 안에서 | 로 구분되어있어.

전용무기 강화 재화 계산 로직을 로그인 여부에 따라 다르게 만들꺼야

전제:
- 플레이어마다 보유 재화 수량이 다름
- 로그인하지 않은 사용자는 보유 재화 정보가 없으므로, 단순히 필요한 총 재화 수량만 계산.
- 로그인한 사용자는 보유 재화 정보를 기준으로 사용 가능한 재화와 부족한 재화를 나눠서 표시.

계산 기준:
- 강화 재료는 등급이 있음
  1. 녹슨
  2. 온전한
  3. 크로뮴
  4. 티타늄

- 계산할 때는 높은 등급부터 사용
  티타늄 → 크로뮴 → 온전한 → 녹슨

비로그인 상태:
- 학생의 weapon_type에 맞는 강화 파츠를 찾는다.
- 필요한 총 경험치를 기준으로 높은 등급 재료부터 필요한 수량을 계산
- 보유 수량은 고려하지 않는다.

로그인 상태:
1. 먼저 사용자의 보유 재화 수량을 확인
2. 학생의 weapon_type에 맞는 강화 파츠와 공이를 계산 대상으로 사용
3. 공이는 bonus_weapon_types가 ALL이므로 모든 weapon_type에 사용할 수 있다
4. 보유 재화로 필요한 경험치를 충분히 채울 수 있으면:
   - 높은 등급 재화부터 사용한 결과를 표시
   - 부족 재화는 표시하지 않거나 0으로 표시
5. 보유 재화가 부족하면:
   - 보유한 재화를 높은 등급부터 먼저 반영
   - 남은 필요 경험치를 계산
   - 부족한 재화 수량을 다시 높은 등급부터 계산해서 표시

출력 예시:
- 사용된 보유 재화 목록
- 추가로 필요한 재화 목록

추가로 중요한 구조가 있어.

전용무기 강화 재화 계산은 별도의 계산 페이지로 만들지 않을 거야.
학생 상세 페이지 안에서 학생의 성장 설정값에 따라 계산 결과가 바뀌는 구조로 만들 거야.

즉, 학생 상세 페이지 상단 또는 성장 설정 영역에서 사용자가 값을 선택하면,
그 선택값을 기준으로 아래 필요 재화창의 내용이 갱신되어야 해.

학생 상세 페이지의 목표 성급 영역에 선택에 따른 성급:
- 목표 전용무기 성급

계산에 필요한 고정 데이터:
- 학생의 weapon_type
- data/growth/weapons_level_cost_table.csv
- data/growth/exclusive_weapon_enhancement_items.csv

로그인 유저일 경우 추가로 필요한 데이터:
- 유저가 보유한 전용무기 강화 재료 수량
- 특히 공이 보유 수량

동작 방식:
1. 학생 상세 페이지에서 학생 데이터를 불러와.
2. 학생의 weapon_type을 확인해.
3. 사용자가 성장 설정 영역에서 목표 전용무기 성급을 선택해.
4. 선택값이 바뀔 때마다 필요한 경험치와 크레딧을 다시 계산해.
5. 로그인하지 않은 유저는 필요한 총 재화만 계산해.
6. 로그인한 유저는 보유 재화를 먼저 반영하고, 부족한 재화만 따로 계산해.
7. 계산 결과는 필요 재화창에 표시해.
8. 필요 재화창은 처음 페이지 로드 시에는 닫혀 있고, 사용자가 클릭하면 드롭다운으로 열리게 해줘.

주의:
- 이 기능은 별도 계산 페이지가 아니라 학생 상세 페이지 내부 기능이야.
- 계산 로직은 UI 코드에 직접 넣지 말고 별도 함수로 분리해줘.
- UI는 성장 설정값을 바꾸면 계산 함수를 호출하고, 결과만 받아서 표시하는 구조로 만들어줘.

추가로 계산 순서를 더 명확히 할게.

로그인 유저의 전용무기 강화 재화 계산은 공이를 먼저 사용해줘.
공이는 bonus_weapon_types가 ALL인 공용 재료니까, 학생의 weapon_type과 상관없이 1.5배 보너스가 적용돼.

로그인 유저 계산 순서:
1. 목표 성급에 필요한 총 전용무기 EXP와 크레딧을 계산해.
2. 유저가 보유한 공이를 높은 등급부터 먼저 사용해서 required_exp에서 차감해.
   티타늄 공이 → 크로뮴 공이 → 온전한 공이 → 녹슨 공이
3. 공이를 사용한 뒤 remaining_exp를 계산해.
4. remaining_exp가 남아 있으면 학생의 weapon_type에 맞는 전용 파츠를 보유 재화에서 높은 등급부터 사용해.
5. 그래도 remaining_exp가 남으면, 부족한 전용 파츠 수량을 높은 등급부터 계산해서 추가 필요 재화로 표시해줘.

비로그인 유저는 보유 재화 정보가 없으니까 공이 보유량은 고려하지 말고,
학생의 weapon_type에 맞는 전용 파츠만 높은 등급부터 필요한 수량으로 계산해줘.

중요:
아이템 수량을 단순히 빼는 방식이 아니라, 각 아이템의 effective_exp를 기준으로 계산해야 해.
공이와 전용 파츠를 사용한 결과가 필요 경험치를 초과하면 over_exp로 따로 계산할 수 있게 해줘.

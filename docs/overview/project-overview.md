# project-overview

## 프로젝트 소개

이 프로젝트는 블루 아카이브의 학생 정보, 픽업 일정, 성장 재화 계산 등을 웹에서 확인할 수 있도록 만든 개인 학습용 웹 프로젝트이다.

## 2. 프로젝트 목표

- 블루 아카이브 학생 데이터를 관리한다.
- 학생 목록과 상세 페이지를 통해 캐릭터 정보를 확인할 수 있게 한다.
- 레벨업, 스킬 성장, 성급 강화 등에 필요한 재화를 계산한다.
- 학생 레벨, 성급, 장비에 따른 스탯을 확인할 수 있다.

## 3. 주요 기능

현재 또는 예정된 주요 기능은 다음과 같다.

### 로그인 및 회원가입

- 로그인한 유저에 한해서 자신이 재화를 관리할 수 있다.

### 통합검색 기능

- 학원, 학생 등 원하는 정보를 검색으로 빠르게 찾을 수 있는 기능

### 학생 정보 관련 기능

- 학생 목록 조회
- 학생 상세 정보 조회
- 학원별 학생 분류
- 학생별 이미지 및 기본 정보 표시

### 픽업 관련 기능

- 현재 픽업 정보 표시
- 과거 픽업 이력 확인
- 과거 픽업 캐릭터 클릭시 그 캐릭터의 상세 페이지로 이동하는 기능

### 계산기 관련 기능

- 학생 레벨업 재화 계산
- 스킬 강화 재화 계산
- 성급 강화 재화 계산
- 장비 강화 재화 계산
- 학생 레벨, 성급, 장비에 따른 스탯 증가량 계산
- 인연 랭크 계산

### 이벤트 관련 기능

- 메인화면에서 현재 진행중인 이벤트들을 확인할 수 있는 기능
- 이벤트 상세 페이지에서 이벤트의 상세를 확인할 수 있는 기능
- 과거에 어떤 이벤트를 했는지 확인할 수 있는 기능

# 코드 설명 문서

이 폴더는 프로젝트 코드를 공부하기 위한 설명 문서를 모아두는 곳입니다.

원본 HTML, CSS, JavaScript, data, tools/scripts 파일은 수정하지 않고, 각 파일의 역할과 연결 관계를 문서로 정리합니다.

## 문서 작성 기준

- 파일 하나를 기준으로 설명합니다.
- 문서가 너무 길어지면 기능 단위로 나눕니다.
- 실제 코드에 있는 내용과 확인 가능한 연결 관계를 우선 설명합니다.
- 추측이 필요한 내용은 `추정`이라고 표시합니다.
- 데이터가 임시값이거나 아직 구현되지 않은 기능은 그대로 표시합니다.
- 수정할 때 주의해야 할 점을 함께 기록합니다.

## 문서에 포함할 내용

- 파일의 역할
- 관련 HTML/CSS/JS/data 파일
- 주요 DOM 요소, 함수, 변수
- 코드 실행 흐름
- 사용된 문법의 의미
- 이 코드가 존재하는 이유
- 수정 시 주의할 점

# 스킬 강화 재화 계산 UI

## 위치

스킬 강화 재화 계산 UI는 독립 메인 메뉴가 아니라 학생 상세 화면에 둔다.

경로:

```text
character-detail.html?id=학생ID
```

예:

```text
character-detail.html?id=kei
```

## 현재 구현 상태

학생 상세 화면의 `필요한 재화` 영역에서 다음 재화를 함께 계산해 표시한다.

- 학생 레벨업 활동 보고서
- 학생 레벨업 크레딧
- 스킬 강화 재화
- 성급 및 전용무기 성급 엘레프

계산 결과는 같은 `itemId` 기준으로 합산한다.  
스킬 재화와 레벨업 재화에서 모두 `credit`이 나오면 하나의 크레딧 카드로 합산해 표시한다.

## 입력 UI

학생 상세 화면은 현재 다음 입력값을 계산에 사용한다.

- 목표 학생 레벨
- 목표 성급 / 전용무기 성급
- EX / Normal / Passive / Sub 스킬별 현재 레벨
- EX / Normal / Passive / Sub 스킬별 목표 레벨

학생의 현재 기준값:

- 현재 학생 레벨은 임시로 1레벨을 사용한다.
- 현재 기본 성급은 `data/students.js`의 `baseStar` 또는 `rarity`를 사용한다.
- 현재 전용무기 성급은 `data/students.js`의 `weaponStar`를 사용한다.

각 스킬은 현재 레벨과 목표 레벨을 가진다.

- EX
  - 현재 레벨: 1~5
  - 목표 레벨: 1~5
- Normal
  - 현재 레벨: 1~10
  - 목표 레벨: 1~10
- Passive
  - 현재 레벨: 1~10
  - 목표 레벨: 1~10
- Sub
  - 현재 레벨: 1~10
  - 목표 레벨: 1~10

레벨 입력은 드롭다운을 사용한다.  
스킬 레벨에는 슬라이드바를 사용하지 않는다.

성급 입력:

- 노란 별은 기본 성급 1~5성을 의미한다.
- 파란 별은 전용무기 1~4성을 의미한다.
- 전용무기 1성은 5성에서 무료 개방으로 계산한다.

## 결과 UI

계산 결과는 필요한 재화 목록으로 표시한다.

각 재화는 다음 정보를 가진다.

- 재화 이름
- 필요 수량
- 검수 필요 여부

`needsReview: true` 재화에는 `검수 필요` 표시를 붙인다.

## 빈 상태

선택된 학생에게 스킬 재화 데이터가 없으면 다음 문구를 표시한다.

```text
스킬 재화 데이터가 아직 없습니다.
```

목표 레벨이 현재 레벨보다 낮거나 같으면 다음 문구를 표시한다.

```text
선택한 레벨 구간에 필요한 재화가 없습니다.
```

레벨업 재화와 성급 재화는 공통 규칙이 있으므로 스킬 재화 데이터가 없는 학생도 계산 가능하다.

## 사용 함수

학생 상세 화면은 다음 계산 함수를 import해서 사용한다.

```text
utils/characterLevelCalculator.js
utils/skillMaterialCalculator.js
utils/starRankCalculator.js
```

## 주의

- 메인 화면에는 스킬 재화 계산기 버튼을 두지 않는다.
- 학생 이름으로 요구량 데이터를 찾지 않는다.
- `fixedPoint` 선물이나 인연랭크 계산기 규칙을 스킬 재화 계산에 섞지 않는다.
- 학생별 엘레프 `itemId`는 아직 안정 데이터가 없으므로 현재는 `${student.id}-eleph` 형태의 임시 ID를 사용한다.

# 학생 목록 UI

## 학생 이름 검색

- `characters.html`의 필터 영역 상단에 배치한다.
- 입력값에 학생 이름이 포함되면 해당 학생만 표시한다.
- 학원, 동아리, 성급, 공격 타입, 방어 타입, 역할 필터와 함께 동작한다.
- 추천 목록은 표시하지 않는다.

## 학생 카드

- 학생 카드는 학생증 느낌의 가로형 카드로 표시한다.
- 좌측에는 대표 이미지 placeholder를 둔다.
- 우측에는 학생 이름, 성급, 소속 학원, 소속 동아리, 역할, 공격 타입, 방어 타입을 표시한다.
- 기본 성급은 `starRank` 값을 사용하고 노란 별 아이콘으로 표시한다.
- 전용무기 성급은 `weaponStarRank` 값을 사용하고 파란 별 아이콘으로 표시한다.
- `weaponStarRank`가 `null`이면 전용무기 성급은 숨기거나 `미개방`으로 표시한다.
- 현재 학생 데이터는 기존 `rarity`를 유지하되, 화면 표시는 `starRank`를 우선 사용한다.
- 학생 카드를 클릭하면 `character-detail.html?id=...`로 이동한다.

# 학생 상세 

## 학생 성장

### 학생 레벨

- 학생 레벨 입력창의 기본값은 1이다.
- 학생 레벨 숫자 입력창은 `type="number"`를 사용한다.
- 숫자 입력창의 최소값은 1, 최대값은 90이다.
- 사용자는 숫자를 직접 입력하거나 숫자 입력창의 위/아래 화살표로 학생 레벨을 조절할 수 있다.
- 사용자는 슬라이드바로도 학생 레벨 값을 조절할 수 있다.
- 숫자 입력창과 슬라이드바는 서로 같은 값을 공유하며 동기화된다.
- 값이 1보다 작아지면 1로, 90보다 커지면 90으로 보정한다.
- 사용자는 학생의 현재 성급을 선택할 수 있다.
- 학생 레벨에 따라 HP, 공격력, 방어력 등 스탯이 계산되도록 구현한다.

### 학생 성급
- 모든 학생들은 기본적으로 1성, 2성, 3성만 존재한다.
- 4성 이하에서 전용무기 성급 선택시 기본 성급은 5성으로 표시된다.
- 전용무기 성급1 성 이상에서 5성 이하 선택시 전용무기 성급은 0으로 돌아간다. 
- 학생 성급에 따라 HP, 공격력, 방어력 등 스탯이 계산되도록 구현한다.
- 기본 성급은의 변수명은 baseStar로 작업한다

### 학생 장비 기능

- 각 학생은 최대 3개의 장비를 가진다.
- 장비 종류와 슬롯 규칙은 `docs/data/data-equipment-calculator.md`를 따른다.
- 1번 장비 칸에는 모자, 장갑, 신발 중 하나가 들어간다.
- 2번 장비 칸에는 가방, 배지, 헤어핀 중 하나가 들어간다.
- 3번 장비 칸에는 부적, 목걸이, 손목시계 중 하나가 들어간다.
- 각 학생의 장비 종류는 학생별 장비 데이터로 고정되며, 사용자는 장비 종류를 선택하지 않는다.
- 사용자는 각 장비의 현재 티어, 현재 상태, 목표 티어를 선택할 수 있다.
- 학생별 장비 데이터가 확정되지 않은 슬롯은 `장비 확인 필요`로 표시하고 계산 입력을 비활성화한다.
- 장비 승급 재화 계산 규칙은 `docs/specs/spec-equipment-calculator.md`를 따른다.
- 장비 티어는 장비별로 독립적으로 선택한다.
- 장비 티어 선택에 따라 추후 학생 스탯이 변경될 예정이다.

### 학생 스킬 표시 데이터

- 학생 스킬 표시 데이터는 학생 `id` 기준으로 연결한다.
- 스킬 슬롯은 `skills.ex`, `skills.basic`, `skills.passive`, `skills.sub`를 사용한다.
- 스킬 슬롯은 EX 스킬, 기본 스킬, 강화 스킬, 서브 스킬 순서로 표시한다.
- `skills.ex`는 EX 스킬, `skills.basic`은 기본 스킬, `skills.passive`는 강화 스킬, `skills.sub`는 서브 스킬에 대응한다.
- 각 스킬 슬롯은 단일 스킬 객체가 아니라 `variants` 배열을 가진다.
- 같은 슬롯 안에 기본 스킬, 조건부 변경 스킬, 상태별 스킬이 2개 이상 존재할 수 있다.
- 각 variant는 `id`, `order`, `name`, `icon`, `cost`, `trigger`, `effects`, `changeRule`을 가질 수 있다.
- 각 effect는 `template`과 `levels`를 가진다.
- 현재 학생 상세 페이지는 전투 시뮬레이션을 하지 않으므로 스킬 변경 조건은 `changeRule` 텍스트로 표시한다.
- 추후 실제 변경 로직이 필요하면 `cycle`, `changeTo` 같은 구조로 확장한다.
- 스킬 variants 데이터가 없는 학생은 기존 스킬 표시 UI가 깨지지 않도록 fallback 표시를 유지한다.
- 전용무기 2성 강화 문구는 전용무기 데이터의 `enhancedSkill.target.slot`과 `enhancedSkill.target.variantId`로 학생 스킬 variants를 찾아 자동 생성한다.
- 전용무기 2성 강화 문구는 `enhancedSkill.nameOverride`가 있으면 이를 우선 사용하고, 없으면 `${skill.name}+로 강화` 형식으로 표시한다.

## 추가할 기능
- 학생 상세 URL은 접근성을 위해 `slug`를 사용하고, 계산 데이터와 저장 데이터 연결은 `students.js`의 숫자 `id`를 우선 사용한다.
- 스킬영역에서 사용자가 현재 레벨이 3인데 목표레벨은 3이하게 될 수 없다.
- 필요한 재화 영역의 보유 수량은 `itemId` 기준으로 저장한다.
- 현재는 백엔드 없이 브라우저 `localStorage`에 저장된 보유 수량을 읽어서 표시한다.
- 보유 수량은 참고용 표시값이며, 스킬 및 성장 재화 필요 수량 계산을 제한하지 않는다.
- 로그인/DB 연동 이후에는 `localStorage` 조회 계층을 유저별 재화 저장 API로 교체한다.
- 전용무기 레벨업 재화 계산은 현재 전용무기 레벨을 Lv.1로 고정하고, 목표 전용무기 성급에 따라 목표 레벨을 정한다.
- 목표 전용무기 1성은 Lv.30, 2성은 Lv.40, 3성은 Lv.50, 4성은 Lv.60까지 계산한다.
- 전용무기 강화 재료는 학생 `weaponType`에 맞는 전용 파츠만 사용하며, 이번 단계에서는 공이를 계산하지 않는다.
- 전용무기 강화 재료는 티타늄, 크로뮴, 온전한, 녹슨 순서로 effective EXP를 기준으로 계산한다.

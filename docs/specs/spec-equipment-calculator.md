# 장비 계산기

## 목적

학생 상세 페이지에서 장비 현재 상태와 목표 상태를 기준으로 필요한 장비 승급 재화와 크레딧을 계산한다.

## 입력

각 장비 슬롯은 다음 입력값을 가진다.

- 장비 종류
- 현재 티어
- 현재 상태
- 목표 티어

현재 티어는 `미착용`, T1~T10을 선택할 수 있다.

현재 상태는 현재 티어가 T1~T10일 때만 사용한다.

```text
LV1
MAX
```

목표 티어는 T1~T10을 선택할 수 있으며, 목표 상태는 항상 해당 티어의 MAX로 고정한다.

## 계산 규칙

- 장비 종류가 선택되지 않은 슬롯은 계산하지 않는다.
- 목표 티어가 현재 티어보다 낮으면 잘못된 입력으로 처리한다.
- 목표 티어와 현재 티어가 같고 현재 상태가 `MAX`이면 필요한 재화는 0이다.
- 목표 티어와 현재 티어가 같고 현재 상태가 `LV1`이면 해당 티어 Lv.1에서 MAX까지의 레벨업 비용만 계산한다.
- 미착용에서 T1 장착은 재화를 소모하지 않는다.
- 미착용에서 T1 MAX를 목표로 하면 T1 장착 비용은 0이고, T1 Lv.1에서 T1 MAX까지의 레벨업 비용은 계산한다.
- T1에서 T2로 승급할 때부터 승급 설계도와 크레딧을 소모한다.
- 목표 티어까지 필요한 모든 승급 구간의 재화를 합산한다.
- 현재 상태가 `LV1`이면 현재 티어 Lv.1에서 현재 티어 MAX까지의 레벨업 비용을 먼저 계산한다.
- 현재 상태가 `MAX`이면 현재 티어의 레벨업 비용은 계산하지 않고 다음 티어 승급 비용부터 계산한다.
- 같은 `itemId` 재화는 하나로 합산한다.
- 장비 레벨업 EXP는 강화석 필요 수량으로 변환해서 표시할 수 있다.
- 장비 레벨업 비용 row, 강화석 데이터, 또는 승급 구간 데이터가 누락되면 조용히 정상 계산으로 처리하지 않고 `needsReview: true`, `isValid: false`, `errorCode: "MISSING_COST_DATA"`로 드러낸다.

## 출력

계산 결과는 필요한 재화 영역에 다른 성장 재화와 함께 표시한다.

각 재화는 다음 값을 구분해서 표시한다.

- 필요 수량
- 보유 수량
- 부족 수량

보유 수량은 계산을 제한하지 않는 참고값이다.
누락된 계산 구간이 있으면 필요한 재화 영역에 검수 필요 안내를 함께 표시한다.

## 저장 규칙

유저 보유 재화 저장은 계산 데이터와 분리한다.

현재는 브라우저 `localStorage`의 다음 키를 사용한다.

```text
bluearchive:owned-material-quantities:v1
```

저장 구조:

```js
[
  { itemId: "equipment-hat-blueprint-t2", quantity: 15 },
  { itemId: "credit", quantity: 1000000 }
]
```

이름, 이미지, 타입, 등급은 저장하지 않고 `data/items.js`에서 조회한다.

## 학생 상세 연결

- 학생 상세 페이지의 장비 영역에서 장비 슬롯 3개를 표시한다.
- 학생별 장비 데이터가 확정된 슬롯은 장비 종류를 고정 표시하며, 사용자가 장비 종류를 선택하지 않는다.
- 학생별 장비 데이터가 확정되지 않은 슬롯은 `장비 확인 필요`로 표시하고 계산 입력을 비활성화한다.
- 장비 입력값이 바뀌면 필요한 재화 영역을 다시 계산한다.
- 목표 티어는 현재 티어보다 낮게 선택할 수 없도록 UI에서 제한한다.
